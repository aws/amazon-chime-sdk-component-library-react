# useDeviceController

The `useDeviceController` hook returns the current device controller from the `MeetingManager`. It is available before a meeting when a `deviceController` was passed to `MeetingProvider`, and during a meeting; otherwise it returns `undefined`. Use it to build custom pre-meeting device UIs.

### Return Value

```javascript
deviceController: DeviceController | undefined;
```

## Importing

```javascript
import { useDeviceController } from 'amazon-chime-sdk-component-library-react';
```

## Usage

The hook depends on the `MeetingProvider`.

```jsx
import React from 'react';
import {
  MeetingProvider,
  useDeviceController,
} from 'amazon-chime-sdk-component-library-react';

const App = () => (
  <MeetingProvider>
    <MyChild />
  </MeetingProvider>
);

const MyChild = () => {
  const deviceController = useDeviceController();

  // Build a custom pre-meeting device UI with `deviceController`.
};
```

### Dependencies

- `MeetingProvider`
